\title{Steering When, Where, and Whether Robots Should Speak}
\subtitle{Data-Efficient Adapters for Full-Duplex Human--Robot Collaboration}

\begin{abstract}
Collaborative board games provide socially rich, rule-based environments with measurable outcomes, making them valuable testbeds for studying embodied human--agent collaboration. We present \platform{}, an open-source platform connecting a digital game interface, a game engine with an inspectable planner, a robot platform, and a dialog manager with two reference implementations using large language models (LLMs). Through dialog, the user can change the robot's plan, which the robot then carries out through coordinated speech, gaze, facial behaviour, and actions on the shared digital board. A pilot in which ten participants completed twenty games demonstrates end-to-end operation. Additional data collection and virtual reality (VR) adaptations of the scenario illustrate its reuse for interaction and social-perception research, offering a route to prototyping agents before physical deployment. We release the game interface, game engine, robot platform, and dialog manager to support reproducible research on decision making and communication in collaborative human--robot interaction.

\end{abstract}
